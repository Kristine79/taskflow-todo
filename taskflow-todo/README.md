# Taskflow — список задач

Небольшое приложение для управления повседневными задачами. Реализовано на React, TypeScript и Vite.

## Возможности

- Добавление задач через поле ввода и кнопку (также поддерживается Enter).
- Переключение статуса задачи.
- Удаление задач.
- Фильтрация: все, активные и выполненные.
- Сохранение списка в `localStorage`.
- Защита от добавления пустых задач и строк из пробелов.
- Отдельное отображение количества активных и выполненных задач.
- Адаптивная вёрстка для мобильных устройств.

## Запуск проекта

Требуется Node.js 18 или новее.

```bash
npm install
npm run dev
```

Откройте адрес, который Vite выведет в терминале (обычно `http://localhost:5173`).

## Production-сборка

```bash
npm run build
npm run preview
```
